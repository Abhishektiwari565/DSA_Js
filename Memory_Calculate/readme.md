# Student Management System (JavaScript)

## 📌 Description
This is a simple Student Management System built using JavaScript. It allows you to add, display, search, and remove students using an array (vector-like structure).

## 🚀 Features
- Add Student (ID, Name)
- Display All Students
- Search Student by ID
- Remove Student by ID

## 🧠 Concepts Used
- JavaScript Classes
- Arrays
- Loops
- Functions
